 Лабораторная работа №3 
 Цель 
1. Представление числа в байтах
 '01-00-00-00'. 
 '00-01-00-00'. 
 '00-00-01-00'. 
 Значение записывается в третьем байте. 'int' всегда занимает 4 байта , поэтому даже маленькое число имеет четыре байта. 
2.
  Порядок байтов - 'BitConverter.
 IsLittleEndian': 'True' на x86/x64.
 - Число: '305419896'. 
 - Hex: '0x12345678'. 
 - Байты: '78-56-34-12'. 
 Младший байт хранится первым little-endian. Само значение числа не меняется. 
 3. 
 Текст и UTF-8
  | Текст      | Символов | Байтов UTF-8 | 
  | ABC        | 3        | 3            |
  | Привет     | 6        |12            | 
  В UTF-8 английские буквы занимают по одному байту, а русские буквы в слове 'Привет' — по два байта. Поэтому число символов и байтов может различаться. 
  4. Английская и русская буква 
  - Латинская A : '41'. 
  - Кириллическая А : 'D0-90'.
   Они выглядят похоже, но это разные символы с разными кодами. Латинская буква занимает один байт, русская — два. 
  5. Обратное преобразование Строка 'Привет' преобразуется в байты через 'Encoding.UTF8.GetBytes()', а обратно — через 'Encoding.UTF8.GetString()'.
   Текст совпадает с исходным. Число '305419896' можно преобразовать в байты через 'BitConverter.GetBytes()' и восстановить через 'BitConverter.ToInt32()'.
Контрольные вопросы:  
1.  Единица хранения данных из 8 бит. 
2.  Тип int занимает 32 бита, то есть 4 байта. 
3. Байтовое представление значения. 
4. Младший байт хранится первым.
5.  Число обычно пишут от старших разрядов, а little-endian хранит младший байт первым. 
6.  Символы в кодировке могут занимать разное число байтов. 
7.  Преобразует текст в байты UTF-8.
8.  Преобразует байты обратно в текст по правилам UTF-8. 
9.  Значение зависит от способа интерпретации данных. 
10. Для числа важны тип и порядок байтов, для текста — кодировка. 
Итоговый вывод
Числа и текст хранятся в виде байтов. Тип int занимает четыре байта, а порядок хранения может быть little-endian. Текст кодируется, например, в UTF-8, где разные символы занимают разное количество байтов. Одинаковая последовательность байтов может иметь разный смысл в зависимости от правил интерпретации.
